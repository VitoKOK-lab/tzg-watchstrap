# 後台登入與上線

## 登入諮詢名單

1. 開啟正式網站，在網址後面加上 `/admin`。
2. 點選「使用 ChatGPT 登入」。
3. 使用 `luxkey.tw@gmail.com` 所屬的 ChatGPT 帳號登入。
4. 登入後可查看客人的需求、預算、款式、選色、聯絡方式與送出時間，並將狀態切換為「待聯繫」或「已聯繫」。

若登入其他 Email，後台會顯示沒有查看權限。管理者名單由正式環境的 `ADMIN_EMAILS` 設定控制，多位管理者可用逗號分隔。

## GitHub 與正式網站的分工

- GitHub 倉庫保存網站程式碼與圖片，不保存客人的諮詢資料，也不提交本機 `.env`。
- 正式網站需要支援 Worker、D1 資料庫與 ChatGPT 登入標頭的執行環境。
- 專案現有 `.openai/hosting.json` 已保存正式 Site 的 project ID；更新時沿用該專案，不另建新站。
- 正式環境必須設定 `ADMIN_EMAILS=luxkey.tw@gmail.com`，否則任何帳號都無法進入後台。

## 日常操作

- 後台網址：`https://正式網站網址/admin`
- 客人送出表單後，資料會自動出現在「諮詢名單」。
- 可用上方篩選器查看全部、待聯繫或已聯繫案件。
- 與客人聯繫後，將該筆狀態改為「已聯繫」。
